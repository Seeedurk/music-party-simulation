# Music Party frontend

React and Vite operator screen for the local round simulation. See [Backend/README.md](../Backend/README.md) for setup and run instructions.

Rounds 1–3 offer random choices from the imported catalog. Later rounds use decayed win history, uniform exploration, and demonstrated-interest scores. The New Game control clears previous round records while retaining the guest roster and songs. Probability distributions are not displayed yet.
